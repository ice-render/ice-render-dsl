# Skill Demo

This demo simulates how an AI Agent uses the `ice-render-dsl` skill.

## Files

- `task.md`: the prompt given to an Agent
- `agent-output.json`: the expected JSON DSL generated by the Agent
- `index.html`: browser renderer that consumes the JSON DSL

## Run

From `ice-render-dsl`:

```bash
npm run build
python3 -m http.server 8766
```

Open:

```text
http://127.0.0.1:8766/examples/skill-demo/index.html
```
